# Changelog

## v1.1.0 — Video quality and playlists

- Choose the video quality you want, from low quality to 4K.
- ODM checks the available quality and clearly tells you when it had to use a lower option.
- Download a complete YouTube playlist with one link.
- Playlist videos are shown in an expandable folder with completed, queued, and remaining counts.
- Choose how many playlist videos can download at the same time.
- Playlist videos are saved together in an automatically named folder.
- Paste several links at once, one link per line.
- Download the same video again without overwriting the previous copy.
- Repeated files receive a safe name such as `video-1.mp4`.
- The Chrome extension shows available qualities on supported video pages.
- Improved notifications, connection errors, pause, resume, cancel, and delete behavior.
- Delete downloads from ODM only, or remove their files from the computer as well.

## v1.0.1 — Chrome Web Store release

- Added the official [ODM Chrome extension](https://chromewebstore.google.com/detail/odm-open-download-manager/lfpiggopnkjdgedghgapjnmijgckebkd).
- Added one-click installation through the Chrome Web Store.
- Added browser-to-ODM download handoff.

## v1.0.0 — First release

- Download files with pause, resume, cancel, retry, and progress tracking.
- Organize downloads by file type and choose custom folders.
- Search and manage completed and active downloads.
